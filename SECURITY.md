# Seguridad

## Versiones mantenidas

La rama `main` contiene la versión mantenida de FORJA.

## Informar una vulnerabilidad

No publiques detalles sensibles en un issue abierto. Utilizá la opción
**Report a vulnerability** de la pestaña Security del repositorio o contactá al
mantenedor desde su perfil de GitHub.

Incluí una descripción del impacto, pasos mínimos para reproducir el problema
y, si es posible, una propuesta de mitigación. No incluyas credenciales, datos
personales ni archivos de terceros.

## Alcance de impresión 3D

FORJA exporta modelos, no G-code. Una geometría válida no garantiza que una
pieza sea segura para cualquier carga o aplicación. El usuario debe revisar el
modelo, elegir un perfil de laminado adecuado y supervisar su impresora.
