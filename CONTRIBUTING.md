# Contribuir a FORJA 3D

Gracias por ayudar a construir una herramienta de diseño 3D más accesible.
FORJA está pensada primero para Argentina y luego para toda Latinoamérica.

## Antes de empezar

1. Abrí una propuesta o describí claramente el problema.
2. Trabajá en una rama separada.
3. Mantené los cambios pequeños y comprobables.
4. Ejecutá las verificaciones antes de enviar el cambio.

```bash
npm ci
npm run lint
npm run typecheck
npm test
```

## Criterios del proyecto

- interfaz clara en español;
- controles cómodos para personas sin experiencia en CAD;
- geometría válida y exportable;
- pruebas para cada corrección o comportamiento nuevo;
- sin afirmar que un archivo está listo para imprimir antes de laminarlo;
- sin perfiles de impresora no validados ni G-code arbitrario.
