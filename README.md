# Forja 3D

**Forja 3D** es un prototipo web orientado a facilitar la creación de modelos 3D personalizables y su exportación en formato STL.

La idea nace como parte de **FD Labs** y busca acercar herramientas de modelado simple a personas que quieren crear piezas sin depender desde el inicio de software CAD complejo.

> El desarrollo del prototipo contó con asistencia intensiva de inteligencia artificial. Mi aporte principal fue la definición del producto, la experiencia de usuario, la priorización de funciones, las pruebas funcionales, la detección de errores y la iteración continua sobre el resultado.

## Estado actual

**Prototipo experimental en desarrollo.**

En este repositorio todavía no se encuentra publicado el código completo de la aplicación. Actualmente contiene la licencia y esta documentación inicial. El proyecto debe considerarse una muestra de concepto y dirección de producto, no una versión final lista para producción.

## Visión del producto

Forja busca permitir que una persona pueda:

- partir de formas predeterminadas;
- modificar dimensiones;
- crear diseños simples de manera visual;
- agregar texto o elementos básicos;
- previsualizar el resultado en 3D;
- exportar la pieza en formato STL;
- reutilizar diseños desde una biblioteca;
- aprender mediante tutoriales integrados.

## Problema que intenta resolver

Muchas personas interesadas en impresión 3D necesitan crear piezas sencillas, pero encuentran una barrera inicial en herramientas de modelado complejas.

Forja explora una experiencia más guiada, visual y accesible para crear modelos básicos y editables desde el navegador.

## Funcionalidades exploradas

- Diseños predeterminados editables.
- Creación libre mediante formas básicas.
- Modificación de medidas.
- Vista previa 3D.
- Exportación a STL.
- Biblioteca de diseños.
- Tutoriales de uso.
- Personalización del nombre del archivo.
- Herramientas para texto, cortes y perforaciones.
- Organización mediante paneles laterales.

La implementación técnica fue generada principalmente con herramientas de IA a partir de instrucciones, pruebas y ciclos de corrección.

Por ese motivo, este repositorio no pretende demostrar autoría manual completa del motor 3D. Sí documenta experiencia real en:

- dirección de producto;
- construcción asistida por IA;
- validación funcional;
- diseño iterativo;
- detección de problemas;
- definición de requisitos;
- toma de decisiones de UX.
